# Certificate Images

Place your instructor's certification images here. 

Recommended naming convention:
- `reiki-master.jpg` - Reiki Master Certification
- `pranic-healing.jpg` - Pranic Healing Certificate
- `hoopono-practitioner.jpg` - Ho'opononopono Practitioner
- `yoga-pranayama.jpg` - Yoga & Pranayama Certification
- `meditation-specialist.jpg` - Meditation Specialist
- `advanced-training.jpg` - Advanced Training Certificate

Image specifications:
- Size: 300x200px minimum (landscape orientation)
- Format: .jpg, .png, or .webp
- Quality: Clear, scannable, professional

Note: You can add more or fewer certificates as needed.
